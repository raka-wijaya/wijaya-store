Penjelasan singkat mengenai fitur yang dibuat
website ini dibuat berbasis react, tailwindcss dan react-router-dom yang memiliki fitur:
1. home: yang menampilkan deskripsi dan gambar serta di bagian home terdapat button buy now yang langsung mengarah ke shop
2. shop: disini menampilkan barang yang diambil langsung dari api serta ada fitur search untuk mencari barang dari api
3. about: disini menampilkan semua informasi dari contact customer service untuk pelanggan
4. cart: disini pelanggan(user) dapat melihat barang yang disimpan oleh user
5. user area: disini ada fitur myprofile, myorders, setting, logout. kita bahasa satu persatu di bagian myprofil: di dalamnya terdapat email, no telpon, alamat dan bio. selain itu user bisa dapat melakukan berubahan data diri, myorders: disini user dapat melihat riwayat pesanan mulai dari di packing, pengiriman dan paket di terima, setting: disini si user dapat merubah password, mengganti ke mode dark dan terakhir logout: disini si user dapat keluar dari akunnya

3.Fitur Penting yang Bisa Digunakan
🛒 Belanja Produk
Klik tombol Buy Now di halaman utama atau langsung ke menu Shop.

Tambahkan produk ke keranjang.

🔍 Cari Produk
Gunakan kolom pencarian di halaman Shop untuk mencari produk berdasarkan kata kunci.

📦 Lihat Keranjang
Klik ikon keranjang (🛒) di navbar kanan atas untuk melihat barang yang telah ditambahkan.

👤 Akun Pengguna
Lihat pesanan sebelumnya, ubah pengaturan, atau logout dari aplikasi.
